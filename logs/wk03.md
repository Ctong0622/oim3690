### Session 06 - CSS Layout

On Thursday, we continued learning CSS and focused more on spacing and layout. We learned about the box model, Flexbox, and Grid. I think this was useful because it helped me understand how different parts of a website can be organized on the page.

1. I learned about the CSS box model. Every HTML element can be thought of as a box with content, padding, border, and margin.

2. I learned the difference between padding and margin. Padding is the space inside an element, while margin is the space outside of it. This helped me understand why some elements have more space around them.

3. I learned about Flexbox and how it can arrange items in a row or column. I think this could be useful for things like navigation bars where several links need to be arranged together.

4. I also learned about CSS Grid. I understand that Flexbox is mostly useful for arranging items in one direction, while Grid can organize items using rows and columns.

5. I am still learning when I should use Flexbox and when I should use Grid. I understand the basic difference between them, but I think I need to use them more in my own website to fully understand them.

## Summary for Session 6

Class 6 continued CSS and focused on how elements are spaced and arranged on a webpage. We learned the box model and the difference between content, padding, border, and margin. We also learned Flexbox and Grid as two ways to create layouts. Flexbox is useful for arranging items mainly in one direction, while Grid is useful for rows and columns. I think these concepts will be helpful when we start building more complete websites.
